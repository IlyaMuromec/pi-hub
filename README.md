В проекте реализован CDC класс с разделением USB на несколько COM портов.
Проверка работы полученных COM портов может быть произведена с помощью прикрепленного к репозиторию скрипта **cdc_test.py**. Скрипт выполняет отправку массива данных на мост, прием ответных данных, контроль их соответствия и индикацию результата.  
В случае если проверяемое устройство выдает наружу rx и tx выводы UARTа, эти выводы долны быть замкнуты между собой.

Скрип написан под линукс и перед его запуском неободимо настроить окружение. В частности запуск скрипта может быть выполнен в wsl, далее описан перечень необходимых действий.

В командной стороке windows необходимо 
1. уставновить wsl: *wsl --install Debian*,
2. переключиться на wsl 1: *wsl --set-default-version 1*.

Далее в командой строке Linux необходимо
1. обновить информацию об актуальных версиях доступных пакетов: *sudo apt-get update*,
2. установить систему управления пакетами python: *sudo apt install python3-pip*,
3. установить пакет pyserial-asyncio: *pip install pyserial-asyncio*
4. при выполнении команды возникнет сообщение с ошибкой. Есть два способа её устранения
    - установить пакет для виртуального окружения,
    - выключить встроенную защиту от глобальной установки пакета командой: *python3 -m pip config set global.break-system-packages true*,
6. дать пользователю права на использоваание dialout: *sudo adduser user dialout*.

Редактировать скрипт и отлаживать работу с ним удобно в Visual Code.
